# Project Documentation: Shadow Tracker (Anti-Theft App)

## 1. Overview
Shadow Tracker is an Android security application designed to capture the thief's photo and the device's real-time location when a shutdown is initiated, and send this data to the owner's email.

## 2. File Directory & Descriptions

| File Name | Location | Description |
| :--- | :--- | :--- |
| **AndroidManifest.xml** | `app/src/main/` | Defines permissions (Camera, Location, Internet) and registers services/receivers. |
| **MainActivity.kt** | `com.sh.shadowtracker/` | Main entry point for permission handling and manual testing. |
| **ShutdownReceiver.kt** | `services/` | Listens for the "ACTION_SHUTDOWN" signal from the Android system. |
| **AntiTheftService.kt** | `services/` | A Foreground Service that orchestrates camera and location capturing. |
| **CameraHelper.kt** | `utils/` | Handles silent front-camera photo capture using CameraX API. |
| **LocationHelper.kt** | `utils/` | Fetches GPS coordinates and generates a Google Maps URL. |
| **EmailHelper.kt** | `utils/` | Sends the captured data via SMTP (JavaMail) to the configured Gmail. |
| **build.gradle.kts** | `app/` | Manages dependencies like CameraX, Google Location, and JavaMail. |

## 3. How It Works
1. **Detection:** The `ShutdownReceiver` triggers as soon as the user (or thief) attempts to power off the device.
2. **Processing:** `AntiTheftService` starts instantly.
3. **Data Collection:**
   - `LocationHelper` generates a Maps link.
   - `CameraHelper` clicks a photo from the front camera.
4. **Notification:** `EmailHelper` sends an email with the photo as an attachment and the location in the body.

## 4. Required Credentials
To function, the app requires:
- **Gmail Address:** For sending the alert.
- **App Password:** A 16-digit secure code generated from Google Account settings.
