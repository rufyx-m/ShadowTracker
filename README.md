# ShadowTracker 🔐

**ShadowTracker** is an Android-based anti-theft and device security application designed to help users monitor and protect their devices.

The project focuses on device security, location tracking, security monitoring, and Firebase-based data management.

## 🚀 Features

- **Location Tracking:** Helps retrieve device location information.
- **Camera Integration:** Provides camera-related functionality.
- **Firebase Integration:** Uses Firebase Firestore and Firebase Storage for data management.
- **Email Integration:** Includes email-related functionality.
- **Anti-Theft Service:** Implements background anti-theft monitoring.
- **SIM State Monitoring:** Includes SIM state change detection.
- **Device Administration:** Uses Android Device Administration capabilities.
- **Security Monitoring:** Includes security-related background services.

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Android SDK
- Firebase Firestore
- Firebase Storage
- XML
- Gradle (Kotlin DSL)

## ⚙️ Setup and Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/rufyx-m/ShadowTracker.git
   ```

2. Open the project in Android Studio.

3. Configure Firebase for your own project.

4. Add your Firebase configuration file:
   `app/google-services.json`

5. Sync Gradle and build the project.

6. Run the application on an Android device or emulator.

## 🔒 Security Note

Firebase configuration files and private credentials are not included in this repository. Configure your own Firebase project before running the application.

## 🎯 Project Objective

The objective of ShadowTracker is to explore Android application development, device security, background services, location services, and Firebase integration through a practical project.
